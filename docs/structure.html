          读启示录最常见的错误，是把它当成按时间先后排列的「未来新闻」。本页先说明全书的结构，再比较四种解经学派与四种千禧年观点，最后整理数字与象征的「词典」。本站采用改革宗常见的渐进平行法（progressive parallelism）与无千禧年立场，同时公平呈现其他观点。

          一、作者自己给的大纲：启1:19

          经文内容
          「所看见的」第1章人子在灯台中间的异象
          「现在的事」第2–3章七个教会的现况
          「将来必成的事」第4–22章从天上的视角看整个教会时代直到终局

          注意：「将来」是从约翰的时代说的，并不等于「我们这个时代之后才开始」。4:1「以后必成的事」引用但2:28-29，意思是「末后的日子」已经开始。

          二、渐进平行：七段异象

          🔍 证据：每段都走到终点

          段落结尾经文终局的标志
          1：灯台（1–3）启3:21得胜者与基督同坐宝座
          2：七印（4–7）启6:12-17；7:15-17羔羊忿怒的大日；不再饥渴，神擦去眼泪
          3：七号（8–11）启11:15-18世上的国成了基督的国；审判死人的时候到了
          4：争战（12–14）启14:14-20人子收割庄稼与葡萄
          5：七碗（15–16）启16:17-21「成了！」大城裂为三段，海岛山岭都不见了
          6：巴比伦（17–19）启19:11-21白马骑士再来，兽与假先知被扔进火湖
          7：千年与新天新地（20–22）启20:11–22:5白色大宝座，新天新地
          关键证据：天地的终结在 6:14（天就挪移，山岭海岛都被挪移离开本位）、16:20（海岛都逃避，众山也不见了）、20:11（天地都逃避，再无可见之处）出现了三次——如果全书是单一直线，宇宙就毁灭了三次。所以它们是同一件事从不同角度的重复。

          🪞 两大部分：表面的争战与幕后的争战

          第1–11章：教会 vs 世界

          教会（灯台）受世界逼迫；神用印与号保护并警告。看得见的层面。

          第12–22章：基督 vs 撒但

          揭开幕后：龙、两兽、巴比伦——世界背后的属灵势力，以及它们的结局（按出场的相反次序被消灭：巴比伦 18 → 兽与假先知 19 → 龙 20）。

          四、四大解经学派

          学派核心主张优点问题
          ⏮️ 过去派 Preterist大部分预言在主后 70 年（耶路撒冷陷落）或罗马帝国时期已应验重视原读者处境（「必要快成」）使书对后世教会失去预言力；完全过去派甚至否认将来的再来（异端）
          📜 历史派 Historicist按时间顺序预言从使徒到再来的教会史（宗教改革者常把兽视为教皇）承认书涉及整个教会史各家对应的事件互不一致，不断随时代改写
          ⏭️ 未来派 Futurist第4–22章大多是将来大灾难时期的事重视再来和终局的真实使书对原读者几乎无用；时代论的两个百姓之分
          💡 理想派 Idealist描述善恶争战的永恒原则，不指具体事件适用于各时代忽略真实的历史终点与具体的再来
          ✅ 折衷的理想派（改革宗常见）象征描述整个教会时代的属灵争战，有一世纪的处境，也指向真实的终局兼顾原读者、历代教会与终末需要扎实的旧约背景与象征训练

          👁️ 各段一览：四派怎么读

          段落过去派历史派未来派理想派改革宗
          🕯️ 第一段七封书信写给约翰时代的七个真实教会把七教会看成教会史的七个阶段（以弗所=使徒时代 … 老底嘉=末世冷淡的教会）多数同意是真实教会；时代论者也常加上「七个时期」的读法代表各时代教会的七种属灵状态真实历史教会 + 全教会（7=完全）：每封信「圣灵向众教会所说的」。拒绝把老底嘉等同于「我们这个时代」的推测。
          📜 第二段七印 = 主后 70 年前犹太战争的事件七印 = 罗马帝国从图拉真到君士坦丁的衰落（如 Elliott）4:1 起是教会被提后、七年大灾难的开始神在每一时代对罪恶的审判与对教会的保守七印覆盖从升天到再来：四马是「灾难的起头」（太24），第五印是殉道者，第六印是末日。
          📯 第三段号 = 耶路撒冷被围（66–70）的灾难号 = 蛮族入侵罗马、撒拉逊人（第五号）、土耳其人（第六号）大灾难后半段字面的灾害：天体、蝗虫怪物、二亿大军警告性审判的原则出埃及式的部分审判（⅓），在整个福音时代反复出现，目的是呼召悔改；第七号 = 国度完成。
          🐉 第四段兽 = 尼禄与罗马皇帝；666 = 尼禄兽 = 教皇制度（宗教改革者与清教徒的普遍看法）兽 = 末后一个个人敌基督，统治全世界三年半兽 = 一切神化的国家权力海兽：约翰时代是罗马，也是贯穿历史的逼迫政权；地兽：假宗教；末了有极致的显现（帖后2）。
          🏺 第五段七碗 = 罗马对耶路撒冷的最后审判七碗 = 宗教改革后对罗马教会的审判（法国大革命等）七碗 = 再来前极短期的最后灾难神忿怒的完全彰显与七号平行但更强、更终局：哈米吉多顿 = 19:19 = 20:8 的同一场最后争战。
          🏛️ 第六段巴比伦 = 背约的耶路撒冷（Chilton、Vanderwaal 等）巴比伦 = 罗马教廷巴比伦 = 未来复兴的罗马/世界宗教巴比伦 = 属世诱惑的文化系统巴比伦首先指罗马城（七山），也是历代属世文明的象征；19:11-21 = 基督再来。
          🌅 第七段千禧年 = 现今的福音时代（多为后千禧年过去派）千禧年 = 教会史中的某一千年（如 1260 年数计算）前千禧年：基督再来后在地上作王一千年（时代论：以色列复兴、圣殿重建）撒但被捆绑 = 福音得胜的原则无千禧年（现今实现）：一千年 = 升天到再来；头一次复活 = 灵魂在天上与基督作王；一次普遍复活与审判；新天新地。

          五、千禧年：四种观点

          ✅ 无千禧年（现今实现的千禧年）

          一千年 = 基督升天到再来的现今时期；撒但被捆绑（不能迷惑列国、阻止福音）；圣徒的灵魂与基督在天上作王；末了撒但暂时被释放、最后争战；一次再来、普遍复活、最后审判、新天新地。

          代表：奥古斯丁、加尔文、多数欧陆改革宗（Bavinck、Hendriksen、Hoekema、Beale、Venema）
          后千禧年

          福音广传使世界大规模归信，带来一段（字面或象征的）长时期的公义与和平（千禧年），之后基督再来。

          代表：Jonathan Edwards、Charles Hodge、B. B. Warfield、多位清教徒；当代有神治派
          历史前千禧年

          教会经过大灾难，基督再来，义人复活，基督在地上作王一千年，之后撒但被释放、恶人复活、最后审判。

          代表：游斯丁、爱任纽（早期教父）；George Ladd
          时代论前千禧年

          教会被提（灾前、秘密）→ 七年大灾难（以色列为中心）→ 基督再来 → 在耶路撒冷作王一千年、重建圣殿 → 最后审判。区分以色列与教会两个百姓。

          代表：达秘（1830 年代）、司可福串注圣经、Dallas 神学院

          关于千禧年的这三种观点我们就简单地讲到这里。哪一种观点是正确的呢？这三种观点都一直有，而且现在仍有追随者，所以在评估和判断时，我们要谨慎。尽管如此，我们的信经信条似乎更倾向于最后一种(《比利时信条》第 37条)。后千禧年派认为，福音光传会使全世界的人归信基督，这一观点与很多圣经经文不符，因为圣经预言说，末世的时候世人越来越不敬虔。前千禧年派认为，基督会先悄悄地再来，然后在耶路撒冷作王，这种说法也很难自圆其说，它太拘泥于字面意义。所以，我们只剩下无千禧年派的观点，它虽然不是没有难点，但看起来最符合圣经的指示。

          启示录7：4-7节的经文是不能照字面解释的。各支派如此详细平均的数目---“一万两千”是一个象征性的数字，它说明神子民人数的完全。

          七、解经八原则

          1. 以经解经：先问旧约怎么用这个象征（BC 7：圣经是完全的准则）。
          2. 听见 vs 看见：约翰「听见」狮子，「看见」羔羊（5:5-6）；「听见」十四万四千，「看见」无数的人（7:4,9）——同一实体的两个面向。
          3. 象征优先：书一开始就说是「指示」（1:1，原文 *esēmanen* 与「记号」同字根）。
          4. 原读者能懂：任何解释都必须对第一世纪七教会有意义。
          5. 结构决定次序：平行而非直线。
          6. 基督中心：每一段都回到宝座与羔羊。
          7. 不猜日期：「那日子、那时辰无人知道」（BC 37）。
          8. 在敬拜中读：「念这书上预言的和那些听见又遵守其中所记载的，都是有福的」（1:3）。

          ⚠️ 历史一瞥：教皇是敌基督吗？

          宗教改革时期的信条常把「敌基督」与罗马教皇的职分联系起来，例如威斯敏斯特信仰告白原版第25章第6节（1903 年美国长老会修订时删去此句）：

          📙 威斯敏斯特信仰告白 25.6（教会）RTF-USA 中文译本

          六、除了主耶稣基督，教会别无其他元首。罗马教皇绝非教会的元首，而是敌基督、罪人、和灭亡之子。他在教会中自高自大，抵挡基督和一切称为神的。
