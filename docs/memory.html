13.1 全书骨架口诀

一灯 · 二印 · 三号 · 四龙，
五碗 · 六城 · 七新天。

七段平行：①灯台（1–3）②七印（4–7）③七号（8–11）④龙与兽（12–14）⑤七碗（15–16）⑥巴比伦倾倒（17–19）⑦千年与新天新地（20–22）。

以 · 士 · 别 · 推 · 撒 · 非 · 老

七教会按邮路顺序（启1:11）：以弗所 → 士每拿 → 别迦摩 → 推雅推喇 → 撒狄 → 非拉铁非 → 老底嘉。谐音：「以士别推，撒非老」——「一士别推，撒（手）非老」。两个没有责备：士每拿与非拉铁非（「士非无责」）；一个没有称赞：老底嘉。

印 ¼ · 号 ⅓ · 碗 全

审判层层加强：印揭开灾难的起头，号是部分的警告，碗是最后的忿怒。号与碗都照出埃及十灾：地 · 海 · 河 · 日 · 黑暗 · 幼发拉底 · 空中。

龙 → 海兽 → 地兽 → 巴比伦

出场次序 12 → 13 → 13 → 17；被灭次序相反：巴比伦（18）→ 兽与假先知（19）→ 龙（20）。
