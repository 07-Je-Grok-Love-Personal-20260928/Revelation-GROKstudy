    二、圣经神学：启示录怎样读旧约

    📚 五大旧约来源

    来源主要暗引神学意义
    📕 但以理书人子（但7:13 → 启1:13）；四兽合体（但7 → 启13）；三年半（但7:25 → 启11–13）；封住的书（但12:4 → 启5；22:10「不可封上」）最重要：但以理说「末后的日子」，启示录说「必要快成的事」——但以理所等候的，在基督里开始了。
    📗 以西结书宝座车与四活物（结1 → 启4）；吃书卷（结3 → 启10）；额上画记号（结9 → 启7）；歌革玛各（结38–39 → 启20）；丈量圣殿与城（结40–48 → 启11；21）；殿中流出的河（结47 → 启22）启示录的整体次序与以西结书惊人地平行：异象 → 审判 → 争战 → 新圣殿/城。
    📘 撒迦利亚书四色马（亚1；6 → 启6）；灯台与两橄榄树（亚4 → 启11）；扎他的人（亚12:10 → 启1:7）；不再有咒诅（亚14:11 → 启22:3）被掳归回后的盼望：圣殿与王的复兴，在基督与教会里成就。
    📙 出埃及记十灾（→ 七号、七碗）；逾越节羔羊（→ 羔羊）；祭司的国度（出19:6 → 启1:6；5:10）；摩西的歌（出15 → 启15）；会幕（→ 启21:3）；鹰的翅膀（出19:4 → 启12:14）启示录 = 新的、末世的出埃及：神审判属世的「埃及/巴比伦」，救出他的百姓进入应许之地（新天新地）。
    📒 以赛亚书「圣哉」（赛6 → 启4:8）；巴比伦倾倒（赛21 → 启14；18）；踹酒醡（赛63 → 启14；19）；新天新地（赛65 → 启21:1）；锡安的光（赛60 → 启21:23-26）先知盼望的高峰：新创造与列国归向锡安。

    心版、同住

    🌅 启21:3

    同一个恩典之约（实质都是基督），在不同时代以不同方式施行；启示录展示它的最终成全。

    「我要作你们的神，你们要作我的子民」（）与「神要亲自与他们同在」（）是圣经中圣约的核心公式（荷兰学者常称为 *Bundesformel*）。启示录21:3 把它的三个部分完全合在一起：同住（帐幕）、子民（他们要作他的子民）、神（亲自与他们同在，作他们的神）。并且 21:7 加上大卫之约的「儿子」公式：「我要作他的神，他要作我的儿子」（）。

    📜 启示录 = 圣约文件

    圣约条约要素启示录旧约对应
    序言：立约之主的身份「我是阿拉法，我是俄梅戛……全能者」（启1:8）出20:2 「我是耶和华你的神」
    历史回顾「我知道你的行为」（七封书信）申1–3
    规定：忠心与排他的敬拜不可拜兽、不可拜偶像、不可拜天使（启19:10）第一、二诫
    祝福与咒诅七个「有福了」；七印七号七碗的审判申27–28
    见证人「诚实作见证的」基督；两个见证人申31:26-28
    文件的保护条款不可「加添」、不可「删去」（启22:18-19）申4:2；12:32
    约的记号/印额上受印（启7:3） vs 兽的印记割礼/洗礼；申6:8

    启示录的七封书信与古代近东的「宗主条约」格式相似（这一观察来自 Meredith Kline 等改革宗学者的圣约研究）。

    👑 基督是立约的主

    立约的中保

    羔羊「用自己的血……买了人来」（），立定新约；多特信经第二项教义第8条正是根据这节经文论到基督的死「坚立新约」，有效地拯救选民。

    立约的君王

    他「必用铁杖辖管他们」、「击杀列国」（），是「万王之王」。海德堡要理问答第31问：他是「我们永远的君王，用他的话语和圣灵统管我们，护卫并保守我们」。

    📕 多特信经 第二项教义 第八条 基督之死的果效（节录）CCI 原文 ↗

    这意味着，神定意叫基督藉着十字架上所流的宝血坚立新约，有效地从各民、各族、各国、说各种语言的人中拯救那些（而且只有那些）从永恒中就蒙拣选得救的人，就是圣父赐给基督的那些人；

    🌈 一个恩典之约，两种百姓？

    改革宗圣约神学与时代论最根本的分歧在于：神有一个百姓还是两个？启示录的答案是一个：新耶路撒冷的门写着十二支派，根基写着十二使徒（）；约翰「听见」以色列十四万四千，「看见」万国无数的人（第7章）；摩西的歌就是羔羊的歌（）。HC 54：神的儿子「从世界的起初到末了」为自己召聚一个教会。

    📘 海德堡要理问答 第54问（主日21）CCI 原文 ↗

    54．问：论到“圣而公之教会”，你相信什么？

    答：我相信神的儿子一直在藉着他的圣灵和圣言，从全人类中 ，从世界的起初到末了为他自己召聚、护卫、保守，并存留他的子民，使之在真信心上合一，成为一个蒙选得永生的教会。我相信我现在是，也永远是这教会中活泼的一员。

    📗 比利时信条 第二十七条 论圣而公之基督教会（节录）CCI 原文 ↗

    圣而公之教会从世界的起初就存在，今天仍然存在，并将一直存到世界的末了，因为基督这位永远的王不可能没有臣民。

    🏛️ 威斯敏斯特的表述（长老会改革宗）

    📙 威斯敏斯特信仰告白 7.6（神与人所立的约）RTF-USA 中文译本

    六、福音的实质就是基督，祂在福音时代才显现出来，称为「新约」。在此阶段，约的执行就是通过传讲《圣经》，施行洗礼和主的晚餐。虽然这些圣礼的数量较少，施行起来也较为简单，外在的荣耀也较少，但对约的展现在内容、证据和属灵果效上更丰富，针对的对象也更广泛，即世界各国各族，包括犹太人和外邦人。因此，「旧约」和「新约」并不是两个不同实质的恩典之约，而是同一个约，只是执行方式不同而已。

    四、从不同视角读启示录

    🏛️历史视角

    写给主后一世纪末亚细亚的七个真实教会：帝王崇拜、行业公会、犹太会堂的压力。

    ✍️文学视角

    启示文学 + 先知书 + 书信三种体裁合一；数字、颜色、动物的象征系统；七重结构。

    📜救赎历史视角

    从创造到新创造的终幕；但以理所等候的「末后的日子」在基督里开始。

    🤝圣约视角

    宗主条约格式、祝福与咒诅、约的公式在21:3完成。

    👑基督论视角

    羔羊在宝座中间：全书是「耶稣基督的启示」。

    ⛪教会论视角

    灯台、两个见证人、妇人、新妇：教会的身份与使命。

    🎵敬拜视角

    全书有十几首天上的颂歌：历史的终点是敬拜。

    🛡️牧养视角

    「不要惧怕」：给受苦者的安慰，给妥协者的警告。
