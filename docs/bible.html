2.2.1 📚 五大旧约来源

来源主要暗引神学意义
📕 但以理书人子（但7:13 → 启1:13）；四兽合体（但7 → 启13）；三年半（但7:25 → 启11–13）；封住的书（但12:4 → 启5；22:10「不可封上」）最重要：但以理说「末后的日子」，启示录说「必要快成的事」——但以理所等候的，在基督里开始了。
📗 以西结书宝座车与四活物（结1 → 启4）；吃书卷（结3 → 启10）；额上画记号（结9 → 启7）；歌革玛各（结38–39 → 启20）；丈量圣殿与城（结40–48 → 启11；21）；殿中流出的河（结47 → 启22）启示录的整体次序与以西结书惊人地平行：异象 → 审判 → 争战 → 新圣殿/城。

📙 威斯敏斯特信仰告白 7.6（神与人所立的约）RTF-USA 中文译本

六、福音的实质就是基督，祂在福音时代才显现出来，称为「新约」。在此阶段，约的执行就是通过传讲《圣经》，施行洗礼和主的晚餐。虽然这些圣礼的数量较少，施行起来也较为简单，外在的荣耀也较少，但对约的展现在内容、证据和属灵果效上更丰富，针对的对象也更广泛，即世界各国各族，包括犹太人和外邦人。因此，「旧约」和「新约」并不是两个不同实质的恩典之约，而是同一个约，只是执行方式不同而已。
