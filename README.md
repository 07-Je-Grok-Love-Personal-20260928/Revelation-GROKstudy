- 威斯敏斯特标准逐字引用；经文为和合本（CUV），悬停 / 点击显示原文。

## 🛠 构建

```bash
python3 build/build.py     # 生成 docs/*.html
python3 build/verify.py    # 校验所有 CCI / 威斯敏斯特引文
python3 tools/qa.py        # Playwright 360 / 390 / 768 / 1024 / 1440 溢出检查、展开点击与截图
```

实时地图引擎为本地捆绑的 Leaflet（`docs/assets/vendor/leaflet/`），不依赖 CDN。底图源包括 OpenStreetMap、Esri 街道/地形/卫星、OSM Humanitarian、OpenTopoMap、Wikimedia、CARTO、高德；默认「自动」并在失败时切换；示意图始终可离线阅读。
